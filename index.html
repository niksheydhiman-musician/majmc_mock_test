About This Website

This MAJMC Mock Test website is a bilingual, browser-based practice platform for Semester II students. It combines subject-wise question banks for Radio Broadcasting, Information & Communication Technology, Development & International Communication, and Iconic Personalities of Media with timed practice, instant scoring, wrong-answer review, and local progress tracking.

What it offers

Tiered scoring, bilingual support, timer controls, unit and difficulty filters, retakes, and a personal progress dashboard.

How questions work

Quick practice means choosing a fixed question count like 10, 20, 30, or 50 from the built-in question bank, while the “All Questions” option loads the complete JSON bank for the selected subject only.

How to use it

Choose a subject, apply filters, decide the number of questions, and start practicing instantly in the browser.

The site is built with HTML, Tailwind CSS via CDN, and vanilla JavaScript, and it now includes dedicated JSON files per subject so complete subject banks can be loaded when needed.
